# Remote Sensing

**Summary**: Notes on satellite/Earth observation imagery, geospatial data products, and the tools used to process them.
**Last updated**: 2026-08-24.

---

- [The Technical Debt of Earth Embedding Products](https://cloudnativegeo.org/blog/2026/02/the-technical-debt-of-earth-embedding-products/): Article comparing different earth embeddings. Argues that Earth embedding products accumulate technical debt because every new model ships in an inconsistent, non-interoperable format; calls for standardization (e.g. GeoParquet) and transparent spatial metadata so embeddings become plug-and-play across the ecosystem rather than one-off "snowflakes." Keywords: earth embeddings, technical debt, GeoParquet, interoperability, foundation models, geospatial data. See also [[Embeddings]], [[FME]].
